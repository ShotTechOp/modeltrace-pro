01

"Can this be faked by a proxy injecting a system prompt like 'You are Claude 3.5' or modifying HTTP headers?"

No. 99% of naive model detection tools ask questions like "What model are you?", inspect markdown quirks, or read HTTP response headers. All of those can easily be faked with a 1-line system prompt injection or a proxy regex replace.

ModelTrace does neither. It asks the model to generate hundreds of pseudo-random integers within the interval [1, 355] under zero semantic context. When an autoregressive transformer outputs numbers, its token choices are strictly dictated by its subword BPE tokenizer boundaries and pre-training statistical weight resonances.

"To make a cheap model (like Haiku or Llama 8B) fake Claude Opus's distribution, the proxy would need to compute the 355-dimensional conditional logit distribution of Opus at every token step. The only machine in the world capable of computing Opus's logit distribution is Claude Opus itself."
02

"What if a proxy wraps the prompt with hidden system instructions or preamble noise to trick the test?"

ModelTrace uses Singular Value Decomposition (SVD) on Nuisance Space. The empirical count vector is transformed into Hellinger coordinates:

f(c) = √(c / Σc)
projected = (f - μ) / σ - (projected · BT)B

During calibration, each model was sampled across 12 diverse nuisance environments (multi-paragraph corporate wrappers, system instructions, English/Chinese formats, varying lengths). The orthogonal basis matrix B maps out the distortion caused by wrappers and mathematically subtracts it out, isolating the invariant geometric centroid of the neural network's raw weights.

04

"Can a provider fake hardware generation speed (TPS) and latency?"

Physics cannot be faked. In addition to non-semantic mathematical fingerprinting, ModelTrace sniffs live generation telemetry:

  • Lightweight Models (Claude Haiku, GPT-4o-mini, Gemini Flash) stream at 110–160+ tokens/sec (TPS).
  • Heavy Frontier & Reasoning Models (Claude Opus, GPT-5, o1) run on massive multi-GPU clusters and stream at 25–50 TPS.

If a provider claims they are billing you for a 500B+ flagship model, but the response completes at 140 TPS in 1.3 seconds, GPU memory bandwidth laws prove it is a lightweight model. A scam router cannot magically accelerate a massive flagship model to run 4x faster than physical GPU hardware permits.

05

"What happens if an API serves an unknown model or fine-tune? Does it force a fake match?"

No. Naive classifiers always pick the highest score even if all candidates are completely wrong. ModelTrace includes Out-of-Distribution (OOD) Protection:

If the top centroid similarity falls below the calibrated significance threshold (similarity < 67%), the auditor rejects attribution and triggers a warning: UNANCHORED SIGNATURE / UN-ENROLLED MODEL, showing the nearest mathematical centroid as unconfirmed rather than forcing a false positive.

06

"How does ModelTrace handle naming differences (e.g. dots vs hyphens or shorthand like Claude 4.8)?"

Providers and users often format model identifiers differently (e.g. claude-opus-4.6 vs claude-opus-4-6, claude-4.8 vs claude-opus-4-8, or gpt-4.5 vs gpt-4-5-preview). ModelTrace employs an intelligent slug normalizer that strips punctuation and provider prefixes (anthropic/, openai/) while retaining 100% strict forensic detection against true tier downgrades (Opus → Haiku, GPT-4o → Mini) and cross-family router swaps.
